# Upwork Portfolio Listing — published demo

**Project title**: Customer Support Chatbot & Responsive Ecommerce Demo

**Role**: Frontend Developer / Chatbot Integration

**Description**:
Built Northline Supply, an independent fictional ecommerce concept showcasing a responsive shopping experience and an integrated customer-support assistant. The live guided demo handles product questions, shipping and return FAQs, and explicitly fictional order-status lookups. It includes quick replies, session conversations, loading feedback and an honest fallback for questions outside its knowledge.

The project also contains an optional Cloudflare Worker integration for Google Gemini. Real AI mode should only be listed as active after the backend has been configured, deployed and tested. No real payments, live customers, support agents or order systems are connected.

**Technologies:** HTML, CSS, JavaScript, GitHub Pages; optional Cloudflare Workers / Gemini API.
